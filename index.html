About

I have taught Computer Science & Engineering diploma courses at Government Polytechnics in Karnataka since 2013, at Karwar and, since 2016, at Joida. I teach Python, AI and machine learning, databases, computer networks and IoT under the Karnataka DTE curriculum (C-20 and C-25 NEP).

I also write the material my students learn from: illustrated study notes, lab manuals with tested programs and real outputs, question banks and solved model papers.

In 2026 I completed an M.Tech in Computer Science & Engineering at KLE Institute of Technology, Hubballi. My dissertation, NeuroStress AI, detects stress from EEG brain signals with an ensemble machine learning model and shows the result in a web app.

Tools I work with: Python, scikit-learn, Pandas, NumPy, OpenCV, Keras, Flask, SQL and MongoDB.

Projects

NeuroStress AI

Reads EEG brain signals, extracts features and grades stress with an ensemble of machine learning models. A Flask web app shows each result. Built for my M.Tech dissertation.

Python, scikit-learn, Flask

Code is private until the paper is published.

Driver drowsiness detection

Watches a driver through a laptop webcam, tracks 68 facial landmarks and gives a spoken alert for closed eyes, yawning or head nodding. Runs at 12–20 frames per second. Built during my AI & ML internship.

Python, OpenCV, dlib, NumPy, SciPy

Code on GitHub

FaceAnchor

A face-recognition attendance system designed to stop proxy attendance. It ties each check-in to a class session and uses calibrated LBPH match thresholds.

Read the paper
